# Handoff: AI-Assisted Math Trade Execution Plan

## What I'm Building

A comprehensive execution plan for running an RVA No-Ship Math Trade, structured as an IPO table (Input / Process / Output) with an AI Opportunity grade on every task row. The purpose of staring at this table is to identify which tasks are candidates for agentic AI ownership — and to begin prioritizing which ones to tackle first.

## The Grading System (Two-Axis Framework)

Every task is graded on two dimensions:

- **Feasibility** — Can an agent actually do this? The main drag on this axis is human judgment requirement. Tasks that require discretion, community read, or relationship nuance score lower. Tasks that are mechanical, data-driven, or templated score higher.
- **Leverage** — How much does it matter if an agent does it? Ingredients include repeatability (happens every trade, same way), time saved, and happiness captured.

These two axes form a 2x2 in disguise:

- **High Feasibility + High Leverage** = Start Here
- **High Feasibility + Low Leverage** = Easy Win (low priority)
- **Low Feasibility + High Leverage** = Human-in-the-Loop (agent does mechanical part, pauses for human judgment, resumes)
- **Low Feasibility + Low Leverage** = No Way Jose

Note: Low feasibility doesn't mean never. It means the workflow shape is agent → human checkpoint → agent resumes rather than full autonomy.

## The Bone Structure (Agreed, Two Levels)

1. **Awareness & Recruiting Phase**
   a. Returner outreach
   b. Newbie recruiting
   c. Community buzz / platform posting
   d. Building the participant pool

2. **Offer Up Games Phase**
   a. GeekList creation and launch
   b. Monitoring additions
   c. Answering participant questions
   d. Encouraging participation

3. **Wants Phase**
   a. Monitoring submission progress
   b. Practice runs at submission percentage intervals
   c. Genie pipeline execution on each practice run
   d. Anomaly review
   e. Targeted outreach to nudge submission rates
   f. Watching loops form / reading the trade

4. **Final Run Phase**
   a. Submission deadline management
   b. Final algorithm execution
   c. Genie pipeline execution
   d. Anomaly review and results validation
   e. Results packaging / preparation for announcement

5. **Announce Results Phase**
   a. Publishing results
   b. Communicating to participants
   c. Handling questions and edge cases

6. **Swap Phase — The Glorious Payoff, the Whole Point, the Day the Nitrogen Gets Harvested**
   a. Pre-swap logistics and reminders
   b. Day-of facilitation
   c. Handling no-shows and exceptions
   d. Post-swap wrap-up and community celebration
