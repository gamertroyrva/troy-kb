# Automation Opportunity Matrix — Phase 1: Awareness & Recruiting

*Part of the AI-Assisted Math Trade Organizer project. Step-level population, Phase 1 of 3 (Phases 2-3 to follow).*

**Feasibility** — 1_LOW / 2_MEDIUM / 3_HIGH. How readily this step could be handed to AI/automation for Troy, today. Drags: requires human judgment or discretion; tool/connector doesn't exist or isn't accessible (e.g., no Discord connector); requires capability Troy hasn't built yet. Optional terse color text when not obvious.

**Offload Value** — 1_LOW / 2_MEDIUM / 3_HIGH. How much of the organizer's time/effort gets handed off when this step is automated, driven by current time cost and recurrence. Independent of importance. Optional terse color text when not obvious.
